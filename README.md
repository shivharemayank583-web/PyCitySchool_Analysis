# 📊 School Performance Data Analysis

## 📌 Overview
This project focuses on analyzing school performance data using Python and Pandas. The goal is to explore educational datasets, understand student performance, and identify relationships between school characteristics and academic results.

## 🎯 Objectives
- Analyze overall school performance.
- Calculate average math and reading scores.
- Determine passing percentages in math and reading.
- Compare performance across different school types.
- Analyze the relationship between school budgets and academic performance.
- Explore the impact of school size and spending per student on academic results.

## 🛠️ Technologies & Libraries Used
- **Python** – Programming language.
- **Pandas** – Data manipulation and analysis.
- **NumPy** – Numerical computations.
- **Matplotlib** – Data visualization.
- **Jupyter Notebook** – Interactive development environment.
